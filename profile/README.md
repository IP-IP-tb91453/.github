<p>这篇讲海外住宅IP的实测方法。先把延迟、带宽、丢包、纯净度四个指标拆开定义，再给每种指标的测法与判定区间，然后说明单次测速为什么不可信、多时段采样怎么安排，最后附一张可以长期复用的记录表。</p>
<h2>一、四个指标各自管什么</h2>
<p>延迟是发出请求到收到回应的时间，单位毫秒，决定操作手感。带宽是单位时间搬运的数据量，决定上传下载快慢。</p>
<p>丢包是没到达的包占比，决定连接是否断断续续。纯净度是地址本身的履历，决定它是否被目标站点特殊对待。</p>
<p>带宽标称很大但抖动严重，视频会议照样卡。所以测试要分开做，不能用一次测速的总分代替分项数据。</p>
<h2>二、延迟要拆成三段看</h2>
<p>第一段是你到出口节点，第二段是节点到家庭网关，第三段是网关到目标站点。只有第二段是服务商能控制的。</p>
<p>测法很直接：先连续 ping 出口地址拿基础往返，再用路由追踪看每一跳。耗时突增的那一跳，就是瓶颈所在。</p>
<p>跨洋链路在登陆点之后明显上升，这是物理距离，不是故障。</p>
<h3>采样窗口怎么选</h3>
<p>工作时段和对方国家的晚间各测一轮，间隔六小时以上。跨境拥塞多发生在对方晚间，那个数字更接近真实感受。</p>
<h2>三、带宽要按业务路径测</h2>
<p>公共测速站点走的是就近节点，和业务路径不是同一条。更准的做法是把测速文件放在目标地区，从本地下载或上传。</p>
<p>单流和并发要分开测。单流反映单个连接的上限，并发反映总吞吐。有些线路单流几兆，开八个并发才跑满。</p>
<p>三次取中位数，别取最高值。最高值常是缓存命中或瞬时突发，不能代表持续能力。记录时写清时间、方向、并发数。</p>

<h2>四、稳定性靠长周期采样</h2>
<p>几分钟的测试判断不了稳定性。至少跑二十四小时，每分钟记一次延迟和丢包，画成曲线看形态。</p>
<p>曲线平稳说明线路稳，周期性尖峰说明有拥塞窗口，随机深坑说明链路质量有问题。三种形态的处理方式完全不同。</p>
<p>住宅线路的短暂中断多与家庭网关重启有关。表现为延迟归零若干秒后恢复，对网页影响小，对长连接影响大。</p>
<h2>五、纯净度与速度无关但更关键</h2>
<p>纯净度指这个地址过去被谁用过、有没有留下记录。速度再好，地址本身被重点关注，用起来照样处处受限。</p>
<p>查归属看 ASN 与注册信息，确认是运营商分配给家庭用户的段。查类型看是否有代理标记，公开黑名单可批量比对。</p>
<p>历史表现只能靠试用观察：访问常用站点是否需要额外验证、页面是否被降级、登录是否频繁二次确认。</p>

<h2>六、把结果记成一张表</h2>
<p>每次测试填同一张表，字段固定：日期、时段、出口地址、延迟均值与标准差、上下行带宽、丢包率、验证码次数。</p>
<p>填够两周就能看出真实水平。对比两条线路时，比同一时段的中位数，不比单项最好成绩，这样才有可比性。</p>
<p>测试环境要与业务环境一致。家用宽带测出的结果搬到机房，结论可能完全不同。</p>
<h2>常见问答</h2>
<h3>只看测速站点的分数够不够？</h3>
<p>答：不够。测速站点走就近节点，路径与业务不同，单次结果受瞬时拥塞影响大，建议分时段测三次并记录分项。</p>
<h3>延迟多少算能用？</h3>
<p>答：网页与后台操作两百毫秒以内较顺手，三百毫秒以上明显迟滞。实时业务建议控制在一百五十毫秒以内并关注抖动。</p>
<h3>丢包百分之一影响大吗？</h3>
<p>答：短连接影响很小，长连接会出现重传与卡顿。持续超过百分之三，先排查本地网络再判断线路质量。</p>
<h3>怎么判断地址是不是静态？</h3>
<p>答：隔几小时记一次出口地址，连续几天比对。始终一致即为静态，出现变化说明是动态分配。</p>
